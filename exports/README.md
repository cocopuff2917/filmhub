# Database Export

JSON exports of all MongoDB collections for this app, generated by `/app/scripts/export_db.py`.

## Re-export (fresh snapshot)
```bash
python /app/scripts/export_db.py
```

## Restore to a MongoDB instance
```bash
# For each collection file:
mongoimport --uri "<YOUR_MONGO_URL>" --db <YOUR_DB_NAME> \
            --collection <name> --file exports/<name>.json --jsonArray
```

Example (one-liner for all):
```bash
for f in exports/*.json; do
  name=$(basename "$f" .json)
  [ "$name" = "_manifest" ] && continue
  mongoimport --uri "$MONGO_URL" --db "$DB_NAME" \
              --collection "$name" --file "$f" --jsonArray
done
```

## Notes
- ObjectIds and datetimes are serialized as strings. On import they stay as strings; your app already handles both because models use `PyObjectId`.
- `files.json` contains stored file metadata only; actual uploaded binaries (if any) are not inside this JSON.
- `password_resets` and `notifications` are ephemeral — safe to skip on restore.
