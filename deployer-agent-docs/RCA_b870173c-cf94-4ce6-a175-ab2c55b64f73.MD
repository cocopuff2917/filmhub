# RCA — Deploy run b870173c-cf94-4ce6-a175-ab2c55b64f73 (filmhub-918)

## Outcome
Failed at step **deploy_k8s** (deployment never became ready). The build succeeded and the image rolled out, but the backend container crashed on startup, so nginx's `/health` upstream (`127.0.0.1:8001`) never came up and the rollout timed out. The previous run (8b1dd013…) is still live and serving — the app is NOT down.

## Root cause (verified)
The backend crashes on import. From the pod logs:

```
ModuleNotFoundError: No module named 'pillow_avif'
  from pillow_avif import AvifImagePlugin
  File "/app/backend/server.py", line 32, in <module>
```

`backend/server.py` line 31–32:
```python
from PIL import Image, ImageOps
from pillow_avif import AvifImagePlugin
```

The `pillow_avif` module is provided by the PyPI package **`pillow-avif-plugin`**, which is NOT listed in `backend/requirements.txt`. That file only contains:
```
pillow==12.3.0
```
The Dockerfile installs backend deps with `pip install --no-cache-dir --no-dependencies -r /app/backend/requirements.txt`, so a package that is imported but not declared will never be installed → `ModuleNotFoundError` at boot.

## Reproduction + fix verification (eph sandbox, failed-run source)
- `python3 -c 'import pillow_avif'` → reproduced the exact `ModuleNotFoundError: No module named 'pillow_avif'`.
- `pip install pillow-avif-plugin` → `Successfully installed pillow-avif-plugin-1.6.0`.
- `python3 -c 'from PIL import Image, ImageOps; from pillow_avif import AvifImagePlugin; print("full import chain OK")'` → **full import chain OK**.

## The fix (E1 applies in source)
Add the missing dependency to **`backend/requirements.txt`**:
```
pillow-avif-plugin==1.6.0
```
(Place it near the existing `pillow==12.3.0` line. `pillow-avif-plugin` depends on Pillow, which is already pinned — no other change needed.)

After adding it, redeploy. No deployment-manifest change is required; this is purely a missing Python dependency in app source.
